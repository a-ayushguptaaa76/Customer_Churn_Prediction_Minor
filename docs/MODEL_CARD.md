# Model Card

## Intended use
Educational churn-risk prioritization and portfolio demonstration.

## Target
churn = 1 represents the churn class in the dataset.

## Inputs
Credit score, geography, gender, age, tenure, balance, product count, credit-card indicator, active-member indicator, and estimated salary.

## Limitations
- Static tabular data does not establish causation.
- Churn probability is a model estimate, not certainty.
- The dataset is imbalanced.
- The project does not establish production performance, fairness, calibration, or temporal generalization.
- Do not use this educational model for automated adverse financial decisions.

## Evaluation
Historical baseline metrics are documented in the README. Current reproducible metrics are generated by src.train and written to reports/metrics.json.
